# AutoEscape
## ManualEscape walked so we could add a webui
Basically you can unenroll on a webui without dev mode. All you need is your google account, password, and serial number.

Prerequisites
> playwright, google, protobuf and requests from pip
```
pip install playwright google protobuf requests
playwright install
```
